# Самопомощь — MVP ИИС психологической самопомощи

MVP веб-сервиса по теме ВКР: интеллектуальная информационная система с ИИ-агентом
психологической самопомощи (дневник с анализом, шкалы GAD-7/PHQ-9, техники КПТ,
мониторинг состояния, маршрутизация к специалисту).

Реализован на **чистом Python 3.12 (стандартная библиотека)** — запускается без
установки пакетов. Структура повторяет модули из ВКР, поэтому перенос на
FastAPI/PostgreSQL не требует переписывания бизнес-логики.

## Запуск

```bash
python server.py
```

Откройте http://127.0.0.1:8000 — появится экран входа/регистрации. При регистрации
обязательно принимается цифровое согласие (ФЗ-152): сохраняются временная метка и
SHA-256-хэш документа согласия.

Данные хранятся в локальной SQLite-базе `data/selfhelp.db` (создаётся автоматически).

Настройки через переменные окружения: `HOST` (по умолч. `127.0.0.1`), `PORT`
(по умолч. `8000`), `DATABASE_PATH` (путь к БД). Например:
`HOST=0.0.0.0 PORT=8080 python server.py`.

## Соответствие модулям ВКР

| Модуль ВКР | Реализация в MVP | Точка подключения |
|---|---|---|
| Ввод и фиксация данных | Дневник (текст), оценка настроения, кнопка «Голос» | `app/storage.py`, голос — транскрибация речи (см. ниже) |
| Интеллектуальный анализ | Тональность + когнитивные искажения + триггеры + подбор техники | `app/ai_engine.py` — rule-based заглушка |
| Мониторинг и визуализация | Шкалы GAD-7/PHQ-9, графики динамики | `app/scales.py`, `static/app.js` (canvas-графики) |
| Безопасность и защита данных | Фиксация согласия, хэш документа, Bearer-сессии | `app/auth.py`, шифрование — `storage.encrypt_value` |
| Маршрутизация и коммуникация | Каталог психологов, заявки, сводный отчёт | `app/handlers.py`, PDF-экспорт — заглушка |

## Структура проекта

```
selfhelp-mvp/
├── server.py            # HTTP-сервер (stdlib http.server), статика + API
├── app/
│   ├── config.py        # пути, настройки
│   ├── auth.py          # пароли, сессии, фиксация согласия
│   ├── storage.py       # SQLite (аналог PostgreSQL-схемы)
│   ├── scales.py        # GAD-7 / PHQ-9 и интерпретация
│   ├── seeds.py         # техники КПТ, психологи, экстренные контакты
│   ├── ai_engine.py     # ИИ-анализ (rule-based, интерфейс для реальных моделей)
│   └── handlers.py      # REST-обработчики (роутер)
├── static/
│   ├── index.html       # SPA-разметка (страницы)
│   ├── styles.css       # стили
│   ├── app.js           # клиентская логика, вызовы API, графики
│   └── manifest.json    # PWA-манифест
├── requirements.txt        # пуст (stdlib) — для быстрого билда на Render
└── requirements-fastapi.txt # промышленный стек для переноса
```

## REST API

Публичные: `POST /api/register`, `POST /api/login`, `GET /api/crisis`,
`GET /api/tests/{gad7|phq9}`, `GET /api/techniques`, `GET /api/psychologists`.

С авторизацией (`Authorization: Bearer <token>`):
`GET /api/me`, `POST /api/logout`, `GET/POST /api/diary`, `POST /api/tests/submit`,
`POST /api/requests`, `GET /api/progress`, `GET /api/report`.

## Куда подключать реальные компоненты

- **Тональность (NLP):** в `ai_engine.AIEngine.analyze` замените rule-based счёт на
  классификатор BERT/RoBERTa (Hugging Face `transformers`).
- **Когнитивные искажения (LLM):** в том же методе вызовите LLM со системным
  промптом-классификатором КПТ (список искажений уже задан в `_DISTORTIONS`).
- **Триггеры и техники (RAG):** индексируйте `seeds.CBT_TECHNIQUES` эмбеддингами в
  векторной БД (pgvector/Qdrant) и ищите ближайшие техники по вектору записи.
- **Транскрибация голоса:** на стороне клиента используйте MediaRecorder + WebSocket,
  на сервере — Whisper/Speech-to-Text; в MVP кнопка «Голос» — заглушка-подсказка.
- **PostgreSQL:** `storage.py` уже изолирует SQL; замените SQLite-запросы на
  SQLAlchemy/psycopg2 без изменения остального кода.
- **Шифрование AES-256:** реализуйте `encrypt_value`/`decrypt_value` в `storage.py`
  (ключ из KMS/переменной окружения) и применяйте к тексту дневника.
- **Псевдонимизация PII:** перед отправкой текста в LLM добавьте этап замены имён,
  телефонов и т.п. на маркеры (соответствие ФЗ-152).
- **PDF-отчёт:** по данным `GET /api/report` сгенерируйте PDF (reportlab/weasyprint).
- **PWA:** манифест уже подключён; для офлайн-режима добавьте service worker.

## Деплой — доступ из интернета

Чтобы открывать сервис не только с localhost, есть несколько путей.

### 1. Мгновенный доступ без аккаунта — Cloudflare Tunnel
На своей машине (там, где лежит проект):
1. Скачайте `cloudflared` — https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. Запустите сервер: `python server.py`
3. В отдельном окне: `cloudflared tunnel --url http://localhost:8000`
4. В выводе появится публичный URL вида `https://<случайный>.trycloudflare.com` — открывайте его с любого устройства.

Минус: ссылка временная и действует, пока работает процесс `cloudflared`.

### 2. Через ngrok (нужна бесплатная регистрация)
`ngrok http 8000` — после регистрации и добавления authtoken выдаёт публичный URL.

### 3. Постоянный URL — Render (бесплатный тариф)
Подходит, чтобы дать ссылку комиссии. Нужны аккаунты GitHub и Render.
1. Войдите на render.com через GitHub.
2. New → Web Service → подключите репозиторий с этим проектом.
3. Start Command: `python server.py` (или укажите файл `render.yaml` как Blueprint).
4. Render сам задаст `PORT`; приложение читает его из окружения, `HOST=0.0.0.0` уже прописан в `render.yaml`.

Ограничения бесплатного тарифа Render: диск эфемерный (SQLite сбрасывается при
редеплое/перезапуске), сервис «засыпает» после ~15 мин простоя (первый запрос будит
его ~30–60 с). Для постоянных данных подключите бесплатный Postgres и укажите
`DATABASE_PATH`/строку подключения.

### Доступ по локальной сети (без интернета)
`HOST=0.0.0.0 python server.py` (PowerShell: `$env:HOST="0.0.0.0"; python server.py`)
и откройте с другого устройства в той же Wi-Fi сети по `http://<IP-компьютера>:8000`.

## Ограничения MVP

- Аутентификация — Bearer-токен в памяти, пароль хэшируется SHA-256 (для продакшена:
  JWT + bcrypt/argon2).
- ИИ-анализ — детерминированная заглушка на ключевых словах, а не настоящие модели.
- Данные не шифруются на диске (точка подключения предусмотрена).
- Сервис не заменяет профессиональную помощь; при кризисных признаках показывает
  экстренные контакты и приостанавливает самопомощь.
